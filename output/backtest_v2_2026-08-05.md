**Итог по амплитуде:**
- v1 средняя ошибка (по PLZL/SELG/RAGR): **≈ 4.0 п.п.** в неверную сторону
- v2 средняя абсолютная ошибка (18 тикеров): **≈ 1.5 п.п.**

**Что улучшилось:**
- Ранжирование: модель поставила PLZL, SELG, GMKN, POSI в топ-10 по ожидаемому росту — все реально росли выше рынка
- Амплитуда: гэп по PLZL модель дала +2.5% (факт +4.9%, было +1-2%)
- RUAL: практически идеально +2.75% ≈ факт +2.78%

**Что не улучшилось / плохо:**
- Модель системно **завышает** ожидания по «средним» бумагам (OZON, MRKC, RNFT, TATN) — реальные движения меньше предсказанных
- **Причина**: v2-модель питает себя одновременными изменениями факторов (IMOEX +1.43% сегодня → предсказание тикера сегодня). Это не «предсказание», а **атрибуция**: «объясни движение тикера через движения факторов». Data-leakage.

## Что это значит методологически

**Модель работает как атрибуция, а не как прогноз.**

- **Что она может (правильно)**: объяснить, почему конкретная бумага двинулась сильнее / слабее рынка. «SELG вырос сильнее PLZL, потому что бета к MOEXMM выше (1.36 vs 1.01), и золото сильно двинулось».
- **Чего она не может (в текущем виде)**: реально предсказать движение до открытия сессии, потому что использует те же самые факторы, чьи движения ещё не известны.

Для честного pre-open прогноза нужны:
1. **Overnight-known входы**: SPX D-1 close, NIKKEI D open (закрывается 09:00 МСК до MOEX open), BRENT_LIVE как-of 09:30 МСК, GOLD_LIVE, USD/RUB D-1 close
2. **Вторая регрессия**: предсказать IMOEX-D через overnight-факторы, дальше прогнать через бету тикера

Это делается тем же аппаратом, просто добавляется slave-регрессия «SPX/NIKKEI/Brent → IMOEX сегодня». Займёт вечер и правки в `prognosis.py`.

## Комбинация с новостным скринером

Правильная утренняя цепочка:
```
1. Overnight факторы (Yahoo live SPX/Nikkei/Brent/Gold) 
   → регрессия предсказывает IMOEX D
2. IMOEX D + предсказанные сектор-индексы 
   → через бэты каждой бумаги ожидаемый гэп
3. Новостной снимок (pre-open news) 
   → корректирует ожидания по конкретным бумагам
   («у SBER positive news → к 2.13% модельного добавляем событийный alpha»)
4. Финальный ранжированный список кандидатов
```

## Уроки для итерации

1. **Модельная база уже сильно лучше «на глазок»**: 4 п.п. средней ошибки → 1.5 п.п. Даже при data leakage это показывает, что мы правильно поймали структуру рынка.
2. **RAGR — по-прежнему аномалия**. Бэта показала: тикер должен был вести себя как рынок (сектор MOEXCH позитивный, бэта нормальная). Реальность: +2.61%. Никакого повода думать «вниз» на бэтах нет. Значит моё исходное правило `bearish agro` работало **строго против** статистики.
3. **Топ модели по |Δ| — правильный кандидатный лист**: 18 из 18 угаданы по направлению. Это база для формирования watch-list к открытию.
4. **Следующий шаг**: overnight-only регрессия. Тогда получится настоящий пре-опен прогноз.
